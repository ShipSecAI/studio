Studio is not only a workflow harness in the abstract. It is also a product for
real security operations.

Current public product areas include:

- GitHub scans and PR protection
- cloud posture and cloud inventory
- ASM domains, assets, and scans
- security dashboards and findings pipelines

## GitHub Security Flows

Studio can connect GitHub events to:

- repository scans
- PR-triggered workflows
- comments, check runs, and review-style feedback

## Cloud Security

The cloud surfaces cover:

- AWS
- GCP
- inventory and graph-style collection
- security scan workflows

## ASM

Attack surface management surfaces include:

- domains
- assets
- scans

These are part of the broader workflow and findings model, not isolated tools.

## Dashboards And Findings

Security operations in Studio are tied back into analytics and findings so teams
can go from detection to action in one system.
