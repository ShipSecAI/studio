Report templates are the presentation layer for recurring security output.

Use them when you want:

- consistent formatting across reports
- reusable output structures
- draft and publish workflows for report design

## What The Surface Supports

The current product includes:

- built-in report templates
- organization-published report templates
- draft editing and preview flows
- immutable published versions

## Why Report Templates Matter

Security workflows often produce findings, summaries, and artifacts that need to
be shared with other teams.

Report templates help turn those outputs into something consistent and
repeatable instead of one-off formatting work.

## Product Positioning

Report templates are separate from workflow templates:

- **workflow templates** help you start execution logic quickly
- **report templates** standardize how results are rendered
