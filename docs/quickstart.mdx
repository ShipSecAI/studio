## Start Here

```bash
git clone https://github.com/ShipSecAI/studio.git
cd studio
```

Then choose your lane.

## Source Development With Docker-Backed Infra

```bash
just init
just infra up
just dev
```

This starts the shared backing services in Docker and the Studio apps from source with PM2.

Default local ports:

- frontend: `http://localhost:5173`
- backend: `http://localhost:3211`
- Temporal UI: `http://localhost:8081`

## Full CE Docker Stack

```bash
just ce up
```

This starts infra plus frontend, backend, and worker in Docker.

Default local ports:

- frontend: `http://localhost:5173`
- backend: `http://localhost:3211`
- Temporal UI: `http://localhost:8081`

## Self-Hosting Beyond One Machine

Use the published Studio images:

- `ghcr.io/shipsecai/studio-backend:latest`
- `ghcr.io/shipsecai/studio-worker:latest`
- `ghcr.io/shipsecai/studio-frontend:latest`

Then provide the required service classes described in [Self-Hosting](/self-hosting).

## AI Setup

If you want agent and AI workflows to call your provider directly:

```bash
export CHAT_AI_BASE_URL="https://api.openai.com/v1"
export CHAT_AI_API_KEY="..."
export CHAT_AI_MODEL_ID="gpt-5.4-mini"
```

## First Things To Try

1. Open the workflow templates library.
2. Inspect the seeded security workflows.
3. Create a workflow from a template.
4. Open the component catalog.
5. Explore the MCP and integrations surfaces.

## Common Source Commands

```bash
just init
just infra up
just dev
just ce up
just dev stop
just dev logs
```
