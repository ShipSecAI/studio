## Fastest Path

```bash
git clone https://github.com/ShipSecAI/studio.git
cd studio
just quickstart
```

Open:

- App: [http://localhost:8080](http://localhost:8080)
- Temporal UI: [http://localhost:8081](http://localhost:8081)

## What This Gives You

The quickstart stack is the simplest public self-hosted path.

It brings up:

- frontend
- backend
- worker
- PostgreSQL
- Temporal
- Redis
- MinIO
- Loki
- Redpanda
- ClickHouse
- Neo4j
- Hotplug

Backend migrations are applied automatically during startup.

## Sign In

Default local credentials:

- username: `admin`
- password: `admin`

## Optional AI Setup

If you want AI components and agent flows to call your own model provider:

```bash
export CHAT_AI_BASE_URL="https://api.openai.com/v1"
export CHAT_AI_API_KEY="..."
export CHAT_AI_MODEL_ID="gpt-5.4-mini"
just quickstart
```

If you skip this, Studio still starts normally.

## First Things To Try

1. Open the workflow templates library.
2. Inspect the seeded security workflows.
3. Create a workflow from a template.
4. Open the component catalog.
5. Explore the MCP and integrations surfaces.

## Common Commands

```bash
just quickstart
just quickstart logs
just quickstart status
just quickstart stop
just quickstart clean
```
