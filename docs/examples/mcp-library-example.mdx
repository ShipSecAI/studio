This example shows the core MCP pattern in Studio:

1. register or select one or more MCP servers
2. expose their tools through the MCP Library surface
3. connect those tools to an AI-capable component
4. route the resulting output into a downstream workflow step

## Why This Example Matters

It demonstrates the difference between:

- plain text generation
- agent execution with real tool access

That distinction is central to the “agent-native security workflow harness”
positioning.

## Typical Uses

- cloud investigation
- log or metrics exploration
- tool-assisted triage
- multi-step AI workflows with constrained tool access
