Use Jira when a workflow needs to create tickets, escalate findings, or hand
off work into an issue-tracking system.

## OSS Setup Path

The public product supports two Jira routes:

- Atlassian OAuth for the simpler user-managed path
- self-managed Jira app/web trigger for the app-driven path

## Atlassian OAuth

Use OAuth when you want the simplest way for Studio to create and manage Jira
issues through Jira Cloud APIs.

That path is:

- user-managed
- token-based
- easier for community-edition setups than app deployment

## Jira App / Web Trigger

In practice:

- you deploy or own the Jira app
- you generate the app web trigger URL
- you store that connection in Studio
- Jira-aware workflows call that app directly at runtime

## Self-Hosted vs ShipSec Cloud

ShipSec Cloud uses the hosted Jira discovery and registration path.

In self-hosted Studio, you provide the Jira app and web trigger yourself.
