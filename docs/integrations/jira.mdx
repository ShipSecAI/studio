Use Jira when a workflow needs to create tickets, escalate findings, or hand
off work into an issue-tracking system.

## OSS Setup Path

The public self-hosted model is manual and operator-managed.

Typical options:

- OAuth
- API token
- manual app setup where appropriate for your Jira environment

## What The Public Docs Should Emphasize

For OSS:

- you manage the Jira app or token setup
- you control the credentials
- workflows can create or update Jira issues once the connection exists

## Self-Hosted vs ShipSec Cloud

ShipSec Cloud may provide a smoother managed onboarding path for Jira.

In self-hosted Studio, expect to manage the Jira app or token setup yourself.
