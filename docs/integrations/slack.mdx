Slack is a common destination for workflow output and operational awareness.

Use it for:

- notifications
- scan summaries
- workflow alerts
- bot or app-based messaging flows

## OSS Setup Path

Typical public setup options:

- incoming webhook
- Slack app or OAuth setup

## Common Slack Patterns

- send findings to a channel
- summarize workflow results
- alert on critical scan output
- bridge workflow output into team collaboration

## ShipSec Cloud Callout

ShipSec Cloud may provide a smoother hosted onboarding path for Slack, but the
public docs should fully describe the self-managed webhook/app flow first.
