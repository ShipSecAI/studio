ShipSec Studio uses [`just`](https://github.com/casey/just) as its primary command runner.

Run:

```bash
just
```

or:

```bash
just help
```

## Quickstart

### Start Quickstart

```bash
just quickstart
```

Starts the public single-tenant Docker Compose stack.

### Stop Quickstart

```bash
just quickstart stop
```

### Logs

```bash
just quickstart logs
```

### Status

```bash
just quickstart status
```

### Clean

```bash
just quickstart clean
```

Removes quickstart volumes and data.

## Source Development

### Initialize

```bash
just init
```

Installs dependencies and creates service `.env` files from examples.

### Start Development

```bash
just dev
```

Starts the contributor development stack with:

- shared local infra
- backend
- worker
- frontend

### Stop Development

```bash
just dev stop
```

### Logs

```bash
just dev logs
```

### Status

```bash
just dev status
```

### Clean

```bash
just dev clean
```

## Infrastructure-Only

These commands are contributor-oriented and mainly useful during source development.

```bash
just infra up
just infra down
just infra logs
just infra clean
```

## Multi-Instance Development

```bash
just instance show
just instance use 3
just instance-init 3
just instance-env init 3
just instance-env update 3
just instance-env show 3
```

See [MULTI-INSTANCE-DEV](/MULTI-INSTANCE-DEV) for details.

## Database

```bash
just db-reset
bun --cwd backend run migration:generate
bun --cwd backend run migration:migrate
```

## Validation

```bash
bun run typecheck
bun run lint
bun run test
```

## Short Reference

| Command | Purpose |
| --- | --- |
| `just quickstart` | Start the public Docker quickstart |
| `just quickstart stop` | Stop the quickstart stack |
| `just quickstart clean` | Remove quickstart data |
| `just init` | Install deps and create env files |
| `just dev` | Start contributor development mode |
| `just dev stop` | Stop contributor development mode |
| `just dev logs` | View app logs |
| `just infra up` | Start infra only |
| `just db-reset` | Reset local database |
| `bun run typecheck` | Typecheck workspace |
| `bun run lint` | Lint workspace |
| `bun run test` | Run tests |
