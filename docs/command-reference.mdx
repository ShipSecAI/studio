ShipSec Studio uses [`just`](https://github.com/casey/just) as its primary command runner.

Run:

```bash
just
```

or:

```bash
just help
```

## Source Development

### Initialize

```bash
just init
```

Installs dependencies and creates service `.env` files from examples.

### Start Development

```bash
just dev
```

Starts the Studio app processes from source using the env configuration in your workspace.

### Stop Development

```bash
just dev stop
```

### Logs

```bash
just dev logs
```

### Status

```bash
just dev status
```

### Clean

```bash
just dev clean
```

## Multi-Instance Development

```bash
just instance show
just instance use 3
just instance-init 3
just instance-env init 3
just instance-env update 3
just instance-env show 3
```

See [Development / Multi-Instance Dev](/development/multi-instance-dev) for details.

## Database

```bash
just db-reset
bun --cwd backend run migration:generate
bun --cwd backend run migration:migrate
```

`migration:migrate` runs the repo-aware migration runner. In the public repo it
applies the committed public drizzle SQL, plus any extra migration directories
your environment explicitly configures.

## Validation

```bash
bun run typecheck
bun run lint
bun run test
```

## Short Reference

| Command | Purpose |
| --- | --- |
| `just init` | Install deps and create env files |
| `just dev` | Start contributor development mode |
| `just dev stop` | Stop contributor development mode |
| `just dev logs` | View app logs |
| `just db-reset` | Print guidance for resetting your own runtime-managed database |
| `bun run typecheck` | Typecheck workspace |
| `bun run lint` | Lint workspace |
| `bun run test` | Run tests |
